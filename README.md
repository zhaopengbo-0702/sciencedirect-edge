# ScienceDirect 论文下载助手 v3.1

**当前版本：v3.1** ｜ [⬇ 下载最新版本](https://github.com/zhaopengbo-0702/sciencedirect-edge/releases/latest) ｜ 历史更新记录见 [CHANGELOG.md](CHANGELOG.md)

这是适用于 Microsoft Edge 的本地扩展。它一次处理一篇论文的正文 PDF。

## 安装

1. 解压 ZIP 文件，将解压出的扩展文件夹放在你打算长期保存的位置。
2. 在 Edge 地址栏输入 `edge://extensions/`，打开 **开发人员模式**。
3. 点击 **加载解压缩的扩展**，选择解压后直接包含 `manifest.json` 的 `ScienceDirect-Edge` 文件夹。
4. 在扩展文件夹里双击 `register-desktop-host.cmd` 注册桌面保存组件。从 Edge 工具栏的扩展菜单打开 **ScienceDirect 论文下载助手**。

如果系统计算出的扩展 ID 与 `edge://extensions/` 显示的 ID 不一致，可在扩展目录运行 `register-desktop-host.cmd <扩展 ID>`。移动安装文件夹后，请重新加载扩展并重新注册组件。

已安装旧版时，把新版文件覆盖到原扩展目录，再到 `edge://extensions/` 点 **重新加载**。已打开的论文页需要刷新。

GitHub Releases 的 `latest` 只提供**最新版本**安装包；历史版本的更新记录见 [CHANGELOG.md](CHANGELOG.md)。

## 下载一篇论文

- **已打开 ScienceDirect 论文页**。点击 **下载当前页 PDF**。如果论文页在安装扩展前就已打开，请先刷新一次。
- **手里有题名、DOI 或链接**。把它粘贴到扩展里，再点 **查找并下载 PDF**。题名搜索遇到多个可能匹配时，点击目标论文即可继续下载。
- 已有全文权限时，扩展在后台下载和校验 PDF，下载过程中无需临时标签页。输入题名、DOI 或链接时，扩展会正常打开检索结果或论文页。
- 遇到真人验证时，请在当前论文页或搜索页完成验证。原页面恢复后，扩展可以继续下载，也可以点 **继续下载**。如果站点要求登录，请先在 Edge 登录。
- 如果站点要求从阅读器下载，请在论文页点 **View PDF**，再点击 Edge PDF 阅读器中的下载按钮。下载任务等待 15 分钟，期间扩展会校验对应论文的 PDF 并用论文全名保存到桌面。
- 下载完成后可以点 **在桌面上显示**。PDF 以论文全名保存到 Windows 桌面。Windows 文件名不支持的符号会改为对应的全角字符。遇到不同内容的同名 PDF 会自动加序号。
- Edge 开始下载时会使用论文题名。扩展确认桌面文件保存成功后，会清理 Edge 下载位置中的副本，每篇论文只保留一个文件。
- 扩展检查 PDF 文件头和结束标记后才保存。链接失效、网络中断或文件传输不完整时，扩展会回到原论文页重新取链接，最多重试 3 次。若 ScienceDirect 拒绝访问或要求真人验证，扩展会暂停并提示原因。

下载过程沿用 Edge 中你已登录的 ScienceDirect 或机构访问权限。能否下载订阅论文，取决于该论文页面对你显示的全文权限。扩展使用站点提供的正文 PDF 入口。

题名通过 ScienceDirect 站内搜索查找。DOI 通过 `doi.org` 转到出版方。扩展支持 ScienceDirect 官方站点上的论文，使用浏览器的登录状态，无需填写账号、密码或 API 密钥。

## 常驻下载面板

- 打开 ScienceDirect 页面时，扩展会在**右上角常驻一个「下载助手」面板**（固定位置、不随页面滚动移动）：可直接粘贴题名、DOI 或链接查找下载，下载当前页 PDF、选择候选论文、继续下载、在桌面上显示，并实时显示任务状态。
- 工具栏弹窗与常驻面板顶部都会**显示当前版本号**（如 v3.1），版本号动态读取 manifest，以后每一版自动更新。
- 点面板右上角 **×** 可手动关闭；关闭后右上角保留一个小圆钮「SD」，点击可重新打开。面板只出现在 ScienceDirect 相关页面。
