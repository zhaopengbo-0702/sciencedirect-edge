# ScienceDirect 论文下载助手 v2.5

**当前版本：v2.5** ｜ [⬇ 下载最新版本](https://github.com/zhaopengbo-0702/sciencedirect-edge/releases/latest) ｜ 历史更新记录见 [CHANGELOG.md](CHANGELOG.md)

这是适用于 Microsoft Edge 的本地扩展。它一次处理一篇论文的正文 PDF。

## 安装

1. 解压 ZIP 文件，将解压出的扩展文件夹放在你打算长期保存的位置。
2. 在 Edge 地址栏输入 `edge://extensions/`，打开 **开发人员模式**。
3. 点击 **加载解压缩的扩展**，选择解压后直接包含 `manifest.json` 的 `ScienceDirect-Edge` 文件夹。
4. 在扩展文件夹里双击 `register-desktop-host.cmd` 注册桌面保存组件。从 Edge 工具栏的扩展菜单打开 **ScienceDirect 论文下载助手**。

如果系统计算出的扩展 ID 与 `edge://extensions/` 显示的 ID 不一致，可在扩展目录运行 `register-desktop-host.cmd <扩展 ID>`。移动安装文件夹后，请重新加载扩展并重新注册组件。

已安装旧版时，把新版文件覆盖到原扩展目录，重新注册桌面组件，再到 `edge://extensions/` 点 **重新加载**。已打开的论文页需要刷新。

GitHub Releases 的 `latest` 只提供**最新版本**安装包；历史版本的更新记录见 [CHANGELOG.md](CHANGELOG.md)。

## 下载一篇论文

- **已打开 ScienceDirect 论文页**。点击 **下载当前页 PDF**。如果论文页在安装扩展前就已打开，请先刷新一次。
- **手里有题名、DOI 或链接**。把它粘贴到扩展里，再点 **查找并下载 PDF**。题名搜索遇到多个可能匹配时，点击目标论文即可继续下载。
- 遇到真人验证时，扩展会先尝试自动通过（见下文「Cloudflare 自动验证」）。自动处理失败时，请在原标签页完成验证；ScienceDirect 回到原来的论文页或搜索页后，扩展会自动继续，关掉扩展弹窗也可以。若页面停在其他位置，回到原论文页，或打开扩展点 **继续下载**。
- 如果页面要求登录，请先在 Edge 登录，再回到扩展点 **继续下载**。
- 如果 ScienceDirect 拦截扩展的 PDF 请求，扩展会打开论文页上显示的官方 PDF 链接。Edge 收到 PDF 后会直接下载。扩展会校验文件并用论文全名保存到桌面，扩展弹窗可以关闭。如果 Edge 弹出保存位置窗口，请确认保存位置。
- 下载失败会自动恢复：页面停在验证、PDF 链接失效、页面加载中断、下载标签页被关闭、Edge 阅读器报「未能加载 PDF 文档」等情况，扩展会自动重开论文页、重新获取链接并重试（按 15s、30s、60s、120s 共 4 轮，PDF 阅读器失败另加 3 次自动重开）；一般不需要手动点「继续下载」，只有自动重试全部用尽后才提示手动处理。
- 下载完成后可以点 **在桌面上显示**。PDF 以论文全名保存到 Windows 桌面。Windows 文件名不支持的符号会改为对应的全角字符。遇到不同内容的同名 PDF 会自动加序号。
- Edge 开始下载时会使用论文题名。扩展确认桌面文件保存成功后，会清理 Edge 下载位置中的副本，每篇论文只保留一个文件。
- 扩展检查 PDF 文件头和结束标记后才保存。链接失效、网络中断或文件传输不完整时，扩展会回到原论文页重新取链接，最多重试 3 次。若 ScienceDirect 拒绝访问或要求真人验证，扩展会暂停并提示原因。

下载过程沿用 Edge 中你已登录的 ScienceDirect 或机构访问权限。能否下载订阅论文，取决于该论文页面对你显示的全文权限。扩展使用站点提供的正文 PDF 入口。

题名通过 ScienceDirect 站内搜索查找。DOI 通过 `doi.org` 转到出版方。扩展支持 ScienceDirect 官方站点上的论文，使用浏览器的登录状态，无需填写账号、密码或 API 密钥。

## 常驻下载面板

- 打开 ScienceDirect 页面时，扩展会在**右上角常驻一个「下载助手」面板**（固定位置、不随页面滚动移动）：可直接粘贴题名、DOI 或链接查找下载，下载当前页 PDF、选择候选论文、继续下载、在桌面上显示，并实时显示任务状态。
- 工具栏弹窗与常驻面板顶部都会**显示当前版本号**（如 v2.5），版本号动态读取 manifest，以后每一版自动更新。
- 点面板右上角 **×** 可手动关闭；关闭后右上角保留一个小圆钮「SD」，点击可重新打开。面板只出现在 ScienceDirect 相关页面。
- 下载完成后会**自动关闭**因打开官方 PDF 链接而多出来的空白标签页，不再留下多余页面。

## 验证加速（实测数据）

> 数据来自本机自动化 E2E（真实 Edge + 本地模拟 Cloudflare 挑战页），同一台机器重复测量；真实站点还会叠加 Cloudflare 服务端验证与页面加载时间。

| 版本 | 验证状态轮询 | 首次点击延迟 | 点击间隔 | 点击冷却 | 验证失败首次自动重试 | 实测自动恢复耗时 | 实测单页自动点击耗时 |
|---|---|---|---|---|---|---|---|
| v2.2 | 900 ms | 1200 ms | 2000 ms | 900 ms | 15 s | ≈18.5 s | 基准（未单独测） |
| v2.3 | 900 ms | 1200 ms | 2000 ms | 900 ms | 15 s | ≈17.0 s | ≈4.5–8.2 s（多次运行） |
| v2.4 | 500 ms | 400 ms | 1200 ms | 500 ms | 5 s | ≈7.6 s | ≈4.2 s |
| **v2.5** | **250 ms** | **150 ms** | **800 ms** | **300 ms** | **3 s** | **≈5.4 s** | **≈3.7–5.9 s（多次运行）** |

> 说明：v2.3 是「版本号显示版」，速度参数与 v2.2 相同，本表补充了 v2.3 的实测数据；v2.4/v2.5 为多次运行范围，受本机 Edge 启动与网络波动影响。v2.2 的单页数据未单独测量，故标为基准。

v2.5 额外优化：

- 页面变化检测 250ms→150ms、兜底轮询 800ms→400ms；
- 模拟点击轨迹压缩到最多 14 个点，单次点击从数百毫秒降到约 100ms 级；
- 验证通过后不再等待页面加载，直接续跑；验证会话开始即预挂载调试器，避免偶发数秒的首次点击延迟；
- PDF 下载失败自动重试间隔 12s→6s。

## Cloudflare 自动验证（CF Faker）

下载过程中遇到 ScienceDirect 的 Cloudflare 人机验证时，扩展会自动检测验证页面、模拟点击验证框，必要时刷新页面重试。验证通过后自动继续当前下载，扩展弹窗可以关闭。

- 自动处理失败时，扩展会暂停并提示手动完成验证。在打开的页面完成验证后，下载会按原有流程继续，也可以回到扩展点 **继续下载**。
- 即使挑战页仍在加载中也能检测并处理；自动处理失败会自动刷新页面重试（最多 8 次），仍失败才暂停等待手动完成。
- 如果从旧版覆盖升级到 v2.5，原有下载与桌面保存功能保持不变；如果把扩展装到了新文件夹（扩展 ID 变化），请运行一次扩展目录里的 `register-desktop-host.cmd`。
- 自动验证与自动点击默认开启，无需设置（按你的要求精简了界面，不再显示设置区块）。
- 本功能使用 Edge 扩展的「调试」权限模拟鼠标点击。安装或更新扩展后，Edge 重新加载扩展时若提示新增权限，请确认允许；自动验证期间可能出现短暂的「正在调试此浏览器」提示条，属正常现象，验证结束后自动消失。
- 仅对 ScienceDirect 相关页面和本扩展发起的下载任务生效，不会在其他网站运行，也不提供任何对外接口。
- 不需要 Java 或 JDK，不需要安装 Cloudflare-Faker 服务端或独立浏览器插件，无数据上报。来源与致谢见 [NOTICE](NOTICE)。
